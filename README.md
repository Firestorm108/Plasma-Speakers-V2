# Plasma-Speakers-V2

Dual flyback transformers that produce audio through the modulation of high frequency plasma arcs.

# What is it?
This is version two of my plasma speaker project (https://github.com/Firestorm108/Stereo-Plasma-Speaker). It produces arcs much larger than the previous version, and the heating of the MOSFETs is much lower. This is because it sort of combines two types of oscillating technologies. It uses the same principle of a ZVS driver, switching at zero volts for a great efficiency, but it is able to do this digitally instead of through analog components.
